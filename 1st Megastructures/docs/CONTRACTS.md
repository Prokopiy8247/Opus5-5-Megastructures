Authoritative spec: `MASTER_PROMPT.md` (Part 14 is the game). This file fixes the code-level contracts so parallel builders
produce parts that fit. If the spec and this file disagree, the spec wins for *what*, this file wins for *how it plugs in*;
report the conflict in your final message instead of silently diverging.

## 2. Hard rules for all code
- C# 9, no LINQ / lambdas / boxing / string building in per-frame paths; **zero GC allocation per frame** after load.
- Never use `UnityEngine.Input` (Input System only). Never use `Camera.main` per frame (use `GameState.MainCamera`).
- No `sin`-based hashes. Use integer hashes (PCG / xorshift) and `GameState.Seed`. Everything deterministic.
- Animations derive from `SceneClock.Time` (double), wrapped in double (`SceneClock.Wrapped(period)`), never from `Time.time`.
- Info logs: `Debug.Log("[ABYSS] ...")`. Never log per frame. Errors with `Debug.LogError` (the QA log scan fails on any).
- Units metres/seconds/degrees; yaw from +Z toward +X; pitch positive upward; `AbyssConst.YawPitch(yaw, pitch)` gives the Unity rotation; for lights yaw/pitch is the direction of travel (`AbyssConst.Dir`).
- All numbers come from `AbyssConst` (14.12 + 14.4 + 14.5) and colours from `AbyssPalette` (14.2). Add missing constants to your own file as `const`s next to the code if they are beat-specific; never hard-code a number that already exists in `AbyssConst`.
- No co-planar faces (offset at least 5 mm near, proportionally more far away), bevel near edges 1-3 cm, correct outward normals, 32-bit indices above 65 535 vertices (MeshBuilder does this).

## 3. Runtime flow (owner: core)
`Main.unity` (generated by the lead's editor script) contains: `Bootstrap` (GameBootstrap, ClockDriver, BeatDirector, ProgressDirector,
InstancedRegistryDriver, QaHarness — captures, autotest, bots, perf log and soak; inert without a QA flag), `Player` (CharacterController, PlayerController, AutoWalker), `CameraRig` with the
`Main Camera`, `Key` (the only directional light), `Global Volume` (profile with Tonemapping Neutral, Bloom, ColorAdjustments, WhiteBalance,
Vignette), `Audio` (AudioSource + AudioDirector), `UI` (FadeController), and one GameObject per beat with its `BeatNN_*` component.

Load sequence in `GameBootstrap` (screen black, audio silent): parse `CliArgs` → `MaterialLibrary.MakeCurrent()` → generate textures →
for each beat in order 1..7: `Build(ctx)` (ctx.Root = beat GameObject, ctx.Colliders = child "Colliders") → place player (start or `-beat`/`-progress`)
→ shader warm-up → frames settle → fade in (title timeline 14.11).

Execution order (`[DefaultExecutionOrder]`): ClockDriver -1000, LiftController -200, PlayerController -100, AutoWalker -150 (writes the input
the PlayerController consumes), BeatDirector 0 (calls `BeatBase.Tick` of every built beat each frame), ProgressDirector 10, AudioDirector 20,
CameraRig LateUpdate +100, InstancedRegistryDriver LateUpdate +200 (issues all `Graphics.RenderMeshInstanced`), CaptureHarness +300.

## 4. Shared state
- `GameState` (static): D, E, Beat, Lift, RideSeconds, RideU, RideStarted, CameraPos/Rot, MainCamera, PlayerPos, Cinematic, CaptureMode, AutoTest, Paused, Ended, GoalReached, Seed. Each field has one owner (see the file).
- `SceneClock` (static double Time, Frozen, RealTime).
- Extended progress **E**: d before the ride; D_LIFT + rideSeconds during dwell/ride; d + 121 after the ride. All 14.6 blends are expressed on d (or ride seconds) and evaluated through ProgressDirector.

## 5. Beats (`Megastructure.BeatBase`)
Each beat is `public sealed class BeatNN_Name : BeatBase` in `Assets/_Game/Beats/BeatNN_Name/`. It implements `Index`, `Build(BeatContext)`,
`Tick(in BeatFrame)`, and the QA hooks `CollectSubjects` (key-shot subject bounds, tags of 14.10), `ReportScale` (named measurements from
generated mesh bounds, keys like `"bridge.width"`), `CollectMeshes`, `PrepareCapture(sceneTime)`.
- `Build` must work in EditMode too (`ctx.EditMode == true`): no reliance on play mode, cameras, Time, or coroutines.
- Respect `ctx.Tier` (Full / Simplified / Graybox per the beat's Fallbacks line).
- Create meshes with `MeshBuilder` / `MeshKit`; MeshRenderers with materials from `ctx.Mats` (base `ctx.Mats[MatId.X]`, domain variant `ctx.Mats.Get(MatId.X, FogDomain.Exterior)`, tweak variant `ctx.Mats.Variant(MatId.X, "key", m => ...)`). Never `new Material` elsewhere.
- Colliders: only `CorridorKit` boxes under `ctx.Colliders` (layer Corridor = 8, safety triggers layer 9). Visible meshes have no colliders.
- Local lights: `Light` components created by the beat, explicit `range`, `shadows = None`, intensity `I = E d^2` from 14.2 (tune later). The Key light is owned by ProgressDirector — beats never touch it.
- Renderers: set `shadowCastingMode` deliberately (giants far away: Off; near hard surfaces: On), `lightProbeUsage = Off`, `reflectionProbeUsage = Off`, `allowOcclusionWhenDynamic = false` for huge meshes.
- Persistent skeleton (14.6): far-tier meshes stay active for the whole walk; only near detail tiers switch, by camera distance with `DetailTier`.

## 6. Mesh conventions (`MeshBuilder`, `MeshKit`)
See the header comment of `Runtime/Geometry/MeshBuilder.cs`: clockwise winding (normal = cross(b-a, c-a)), vertex colour R = AO (255 unoccluded),
G = edge wear, UV0 metres where a recipe needs them (ConcreteCyl: x = arc length, y = height), UV1 = generator data (ThinLine axis/radius).
Long members are authored at final length (never non-uniformly scaled). Chunk huge structures (walls, columns: 200 m chunks with chunk-local
vertex positions; the GameObject transform carries the chunk origin).

## 7. Instancing and detail tiers (core owns the implementation; signatures are fixed)
```csharp
public sealed class InstancedBatch {
    public InstancedBatch(string name, Mesh mesh, Material material, ShadowCastingMode shadows = ShadowCastingMode.Off,
                          bool receiveShadows = true, int layer = 0, float chunkSize = 200f);
    public void Add(Matrix4x4 objectToWorld);   // before Seal
    public void Seal();                          // spatial chunks of chunkSize, <= 511 instances per call, bounds inflated 10%
    public bool Visible { get; set; }            // default true
    public float Fade { get; set; }              // _AbFade value for the whole batch (1 = opaque), via a per-batch MaterialPropertyBlock
    public int Count { get; }
}
public static class InstancedRegistry { public static void Register(InstancedBatch b); public static void Unregister(InstancedBatch b); }
public sealed class DetailTier {   // near/far swap by camera distance with hysteresis and dithered cross-fade (never alpha blend)
    public DetailTier(string name, Bounds worldBounds, float nearDistance = 150f, float hysteresis = 20f, float fadeWidth = 20f);
    public void AddNear(Renderer r); public void AddFar(Renderer r);
    public void AddNear(InstancedBatch b); public void AddFar(InstancedBatch b);
    public void Update(Vector3 cameraPos);       // call from Tick; sets _AbFade near = c, far = -(1 - c); disables fully hidden renderers
    public float Coverage { get; }               // c: 1 = near fully shown
}
```
`_AbFade` convention (all opaque Megastructure shaders, colour and depth passes): f >= 0 -> pixel kept where noise < f; f < 0 -> pixel kept where
noise > 1 + f. Noise = static interleaved gradient noise of the pixel position. So near = c and far = -(1 - c) are exact complements.

## 8. Materials and shaders (shader builder owns `Assets/_Game/Shaders/**`, the editor material generator and procedural textures)
Base materials, one per `MatId` (see `Runtime/Rendering/MaterialLibrary.cs`), assets `Assets/_Game/Materials/M_<MatId>.mat`, referenced by
`Assets/_Game/Settings/MaterialLibrary.asset`. Shader property names are in `Runtime/Rendering/ShaderIds.cs` (material: `_BaseColor`, `_AbDomain`,
`_Recipe`, `_Roughness`, `_Metallic`, `_ThinLine`, `_AbFade`, `_EmissionColor`, `_EmissionStrength`, `_CardTop`, `_CardBottom`, `_MinPixels`; globals
`_AbFog*`, `_AbAmb*`, `_AbPixelAngle`, `_AbTime`, `_AbDitherParams`, `_AbLampIgnite`, `_AbBeamFade`, `_AbFanTheta`, `_AbSkyBlend`, `_AbSunDir`,
`_AbExtSunDir`, `_AbScatter*`, `_AbKeyChamfer` (ring-chamfer Key share: amplitude, y0, falloff length, y of zero; R2-06), `_AbRingBand` (shaft axis x, z, inner and outer hex radius of the ring band; R2-06)). Globals are linear colours set with `SetGlobalVector`.
- Every Megastructure shader includes `Include/AbyssFog.hlsl` and applies `AbyssApplyFog(rgb, positionWS, domain)`; Unity fog is off.
- Lit shaders follow the URP Lit passes (ForwardLit, ShadowCaster, DepthOnly, DepthNormals), Forward+ light loop, SRP Batcher CBUFFER, instancing.
- Ambient: domain 0 from the `_AbAmb*` trilight globals; domains 1 and 2 from constant per-domain trilights (their fog colours x 1.2, `AbTrilight(n, domain)`).
  Reflections ONLY from `FogSky(reflect(-V, N)) * fresnel * AO` (no probes, no SH).
