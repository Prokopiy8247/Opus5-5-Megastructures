## Русский

### Windows 10 / 11

1. Скачайте проект: на странице репозитория нажмите зелёную кнопку **Code → Download ZIP**.
2. Распакуйте архив: правой кнопкой по ZIP → **«Извлечь всё»**.
3. Откройте папку **`1st Megastructures`** и дважды щёлкните **`PLAY_WINDOWS.bat`**.
4. Если появилось синее окно «Windows защитила ваш компьютер» — нажмите **«Подробнее» → «Выполнить в любом случае»**.

### macOS (Intel и Apple M1–M4)

1. Скачайте проект: **Code → Download ZIP**, распакуйте двойным щелчком.
2. Откройте папку **`1st Megastructures`**, щёлкните **правой кнопкой** по **`PLAY_MAC.command`** → **«Открыть»** → **«Открыть»**.
3. Если macOS пишет, что файл нельзя открыть: **Системные настройки → Конфиденциальность и безопасность** → внизу **«Всё равно открыть»**, затем повторите шаг 2.

Не получилось? Откройте программу **«Терминал»**, напечатайте `bash ` (с пробелом в конце), перетащите в окно файл `PLAY_MAC.command` и нажмите **Enter**.

### Управление

| Клавиша | Действие |
|---|---|
| W A S D + мышь | идти и смотреть |
| Shift | быстрый шаг |
| C | автопрогулка (камера идёт сама — удобно для записи) |
| Esc | пауза: продолжить, заново, выход |
| Alt+Enter или F11 | полный экран / окно |

Прогулка длится около 11 минут.

## English

### Windows 10 / 11

1. Download the project: on the repository page click the green **Code → Download ZIP** button.
2. Unzip it: right-click the ZIP → **Extract All**.
3. Open the **`1st Megastructures`** folder and double-click **`PLAY_WINDOWS.bat`**.
4. If a blue "Windows protected your PC" window appears, click **More info → Run anyway**.

### macOS (Intel and Apple M1–M4)

1. Download the project: **Code → Download ZIP**, then double-click the ZIP to unzip it.
2. Open the **`1st Megastructures`** folder, **right-click** **`PLAY_MAC.command`** → **Open** → **Open**.
3. If macOS says it cannot be opened: **System Settings → Privacy & Security** → scroll down → **Open Anyway**, then repeat step 2.

Still not working? Open the **Terminal** app, type `bash ` (with a space at the end), drag `PLAY_MAC.command` into the window and press **Enter**.

### Controls

| Key | Action |
|---|---|
| W A S D + mouse | walk and look |
| Shift | walk faster |
| C | auto-walk (the camera walks by itself — handy for recording) |
| Esc | pause: resume, restart, quit |
| Alt+Enter or F11 | fullscreen / window |

The walk takes about 11 minutes.
