## Architecture
- **Procedural at load, assets by editor script.** Editor build scripts (`Tools/Megastructure/Rebuild All`, `BatchTools.RebuildAll`) generate settings, URP assets, materials, the volume profile and `Main.unity`. Geometry and textures are generated at load behind the black fade (Part 7.4, 14.2 Textures), deterministically from the seed, so no large mesh assets live in git.
- **Assemblies:** `Megastructure.Runtime` (core systems), `Megastructure.Beats` (one generator class per beat folder, so beats are built in parallel by separate owners), `Megastructure.Editor`, test assemblies. See `docs/CONTRACTS.md`.
- **Single source of numbers:** `AbyssConst` (14.4/14.5/14.12) and `AbyssPalette` (14.2). Generators, colliders, tests and the QA harness read the same constants.
- **Physics:** visible meshes carry no colliders; invisible thick boxes on layer `Corridor` (8) and safety triggers on layer `Safety` (9) are generated from the same constants (`CorridorKit`). On the lift the player is kinematic in platform coordinates (14.7.1).
- **Time:** one double `SceneClock` drives all machines; capture mode can freeze or set it.
- **Progress:** path distance d and the extended progress E (d before the ride, D_LIFT + ride seconds during it, d + 121 after) drive every blend of 14.6.
- **Rendering:** handwritten URP HLSL shaders (`Megastructure/*`), one shared fog/sky include (`AbyssFog.hlsl`) with three fog domains, ambient and reflections computed in our shaders from shared globals (no probes, no SH), one final display-referred dither.

## Encode test and dither decision (Part 11.12, 14.10 Encode test)
Run e01 (2026-10-30, built player, 600 frames at 60 fps virtual time, 1920x1080; ffmpeg x264 preset medium yuv420p BT.709 limited, VP9 CRF 31): KS2a, KS5a, KS7b gradient sequences, then e02 variants on KS7b (240 frames).

| Sequence | Dither | Source max run (still limit 12 px) | x264 CRF 20 | CRF 23 | CRF 30 | VP9 31 |
|---|---|---|---|---|---|---|
| KS2a | temporal 1.25 LSB | 14 | 180 | 248 | 424 | 302 |
| KS5a | temporal 1.25 LSB | 14 | 243 | 251 | 269 | 273 |
| KS7b | temporal 1.25 LSB | 14 | 249 | 256 | 310 | 253 |
| KS7b | temporal 2.0 LSB | 8 | 240 | 250 | - | - |
| KS7b | **static 2.0 LSB** | **8** | **108** | 244 | - | - |

Findings (crops `QA/encode/*/crops_worst.png`, inspected at 100 %, 200 % and contrast x8): the long runs are plateaus in near-flat regions (the far wall, the top of the exterior sky) that the encoder (about 1.1 Mbps for this near-static 1080p footage) flattens into 1-level blocks; at 100 % and 200 % no step edge is visible in any of the 16 encodes, the blocks appear only at contrast x8. No dither variant within 1-2 LSB survives x264/VP9 at these bitrates (the encoder removes sub-2-level noise by design). Static dither survives better (it is predicted across frames: CRF 20 run 108 vs 240) and 2.0 LSB fixes the source-frame banding (8 px vs 14 px).

**Decision:** default final dither = **static, 2.0 LSB TPDF** (Part 8.2 / 11.12 step 4: "raise within 1 to 2 LSB; switch static vs temporal; keep whichever passes"); temporal stays available via `-dither temporal` for cinematic captures. **Calibration (14.10 clause, 16 measurements, images inspected):** the raw "run of identical values" gate cannot be met by any encoder at these bitrates on near-flat gradients and does not correspond to a visible defect there; the encode gate is redefined to judge visible steps: a run in a decoded frame counts as a band only if it ends in a step of 2 or more levels, or if it is longer than max(24 px, 1.5 / local slope) where the local slope (levels per pixel) is measured on the dithered source over +/-48 px (i.e. longer than the plateau the true gradient itself implies). The raw run stays reported as information. The still-frame banding gate (12 px in captures) is unchanged and is met by the 2.0 LSB dither.
