# Thread — how to play / как запустить

[English](#english) · [Русский](#русский)

## English

### Windows
1. On the GitHub page click **Code → Download ZIP**. Unzip it: right-click the ZIP → **Extract All**.
2. Open the folder **`3st Megastructures`** and double-click **`PLAY_WINDOWS.bat`**.
3. If you see "Windows protected your PC", click **More info → Run anyway**.

### Mac
1. On the GitHub page click **Code → Download ZIP**. Double-click the ZIP to unzip it.
2. Open the folder **`3st Megastructures`**, right-click **`PLAY_MAC.command`** → **Open** → **Open**.
3. If macOS says the file can't be opened, go to **System Settings → Privacy & Security**, scroll down, click **Open Anyway**, and try again.
   Still blocked? Open **Terminal**, type `bash ` (with a space), drag `PLAY_MAC.command` into the window and press **Enter**.

### Controls
| Key | Action |
|---|---|
| W A S D | walk |
| Mouse | look around |
| Shift | walk faster |
| C | cinematic mode: the game walks by itself (good for recording) |
| Esc | pause |
| Alt+Enter or F11 | full screen |

The walk takes about 10 minutes. You need Windows 10/11 (64-bit) or a recent macOS (Intel or Apple silicon).
The Mac version was built on Windows and has not been tested on a real Mac.

## Русский

### Windows
1. На странице GitHub нажмите **Code → Download ZIP**. Распакуйте архив: правый клик по ZIP → **Извлечь всё**.
2. Откройте папку **`3st Megastructures`** и дважды кликните **`PLAY_WINDOWS.bat`**.
3. Если появится «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**.

### Mac
1. На странице GitHub нажмите **Code → Download ZIP**. Дважды кликните ZIP, чтобы распаковать.
2. Откройте папку **`3st Megastructures`**, правый клик по **`PLAY_MAC.command`** → **Открыть** → **Открыть**.
3. Если macOS пишет, что файл нельзя открыть: **Системные настройки → Конфиденциальность и безопасность**, пролистайте вниз, нажмите **Всё равно открыть** и попробуйте ещё раз.
   Всё ещё не открывается? Откройте **Терминал**, напишите `bash ` (с пробелом), перетащите в окно файл `PLAY_MAC.command` и нажмите **Enter**.

### Управление
| Клавиша | Действие |
|---|---|
| W A S D | ходьба |
| Мышь | обзор |
| Shift | идти быстрее |
| C | кино-режим: игра идёт сама (удобно для записи) |
| Esc | пауза |
| Alt+Enter или F11 | полный экран |

Прогулка длится около 10 минут. Нужен Windows 10/11 (64-бит) или свежая macOS (Intel или Apple silicon).
Версия для Mac собрана на Windows и на настоящем Mac не проверялась.
